# Интернет-магазин Skystore

## Описание
Skystore - это веб-приложение интернет-магазина, разработанное на Django. Проект включает в себя главную страницу с каталогом товаров и страницу контактов с формой обратной связи.

## Функциональность
- Главная страница с каталогом товаров
- Страница контактов с формой обратной связи
- Адаптивный дизайн с использованием Bootstrap 5
- Валидация форм на стороне клиента и сервера
- Отображение уведомлений об успешной отправке формы

## Установка и запуск

### Требования
- Python 3.8+
- Poetry (менеджер зависимостей)
- Django 4.2+

### Инструкция по установке

1. Клонируйте репозиторий:
```bash
git clone https://github.com/eburgcustom/homework_22_django.git
cd homework_22
```

2. Установите Poetry (если ещё не установлен):
```bash
pip install poetry
```

3. Установите зависимости:
```bash
poetry install
```

4. Активируйте виртуальное окружение:
```bash
poetry shell
```

5. Примените миграции:
```bash
python manage.py migrate
```

6. Создайте суперпользователя (опционально):
```bash
python manage.py createsuperuser
```

7. Запустите сервер разработки:
```bash
python manage.py runserver
```

8. Откройте в браузере:
- Главная страница: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin/

## Управление зависимостями

### Установка новой зависимости:
```bash
poetry add имя-пакета
```

### Установка зависимостей для разработки:
```bash
poetry add --group dev имя-пакета
```

### Обновление зависимостей:
```bash
poetry update
```
